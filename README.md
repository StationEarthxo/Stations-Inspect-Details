# Station's Inspect Details

A tiny cosmetic RuneLite plugin that rotates the native 3D-derived inventory
sprite while the mouse is hovering over an item. Only the exact hovered slot is
animated, even when the inventory contains duplicate items.

Choose which categories spin: food, potions and drinks, armour and clothing,
weapons, tools, or other items. It does not alter clicks, menus, dragging,
quantities, item IDs, or server state.

Equipment can use a left-to-right spin, forward tumble, or mixed rotation.

Right-click any item and choose **Inspect** to open a large, authentic
in-game model viewer. Drag the item to rotate it, use the mouse wheel to zoom,
and press Escape or click outside the viewer to close it.

The Inspect option can appear on every right-click, or only while Shift is held.

New collection-log messages also make the collected item inspectable directly
from chat. Opening it that way adds a special first-time sparkle celebration.
